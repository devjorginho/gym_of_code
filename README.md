
# Temperature Converter

This is a simple C program that allows you to convert between Celsius and Fahrenheit. The program offers two conversion options:

1. Celsius to Fahrenheit
2. Fahrenheit to Celsius

## How It Works

- The program prompts the user to choose the desired conversion.
- After choosing, the user inputs the temperature value in the selected unit.
- The program then performs the conversion and displays the result.

## Executables

The project generates two executables:

- **For Linux**: Executable named `converter` (generated as `a.out` or `converter` depending on the compilation process).
- **For Windows**: Executable named `converter.exe`.

## How to Use

### On Linux:

1. Compile the C code (if not already compiled):

```bash
gcc -o converter converter.c
```

2. Run the program:

```bash
./converter
```

### On Windows:

1. Download the `converter.exe` file.
2. Double-click the file to run it.

The program works directly in the terminal (Linux) or the Windows interface.
